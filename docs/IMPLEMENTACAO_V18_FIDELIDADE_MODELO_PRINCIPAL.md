# V18.1 — Fidelidade visual do modelo principal consolidado

Modelo homologado: `MODELO DE RELATORIO_ - Google Planilhas2.pdf`.

## Regra visual oficial

O relatório principal deve manter **todas as nove colunas na mesma folha**, sem separar a planilha em faixas horizontais:

1. Dia
2. Código
3. C/B
4. Especificação
5. Entrada/Banco
6. Saída/Banco
7. Entrada/Caixa
8. Saída/Caixa
9. Saldo C/B

Para janeiro/2026, o modelo homologado possui **5 páginas A4 paisagem**, preservando a sequência original dos 87 lançamentos.

PDF e Excel usam a mesma base oficial. Cores, bordas, cabeçalho, zeros à esquerda dos códigos, totais e saldo acumulado seguem o modelo.

O Excel é configurado para impressão em uma página de largura (`fitToWidth=1`), sem quebra horizontal entre as colunas.

A referência contém um `#REF!` no campo de observação, mas o sistema **não reproduz erro de fórmula**: nesse ponto gera `-`, preservando a aparência sem introduzir erro no arquivo Excel.
