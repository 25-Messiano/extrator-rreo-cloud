FLUXO NACIONAL RREO - APPDOWELEVER

Fonte principal de entrada:
  bucket: appdowelever-arquivos
  prefixo: 01_Arquivo_dos_Estados_RREO_e_FNDE/4_APPDOWELEVER/

Estrutura:
  <ano>/<codigo_estado>_<nome_estado>_<UF>/B<bimestre>/*.pdf

Exemplo:
  2025/17_Tocantins_TO/B6/RREO_Municipal_2025_Abreulandia-TO.pdf

Processamento nacional:
  1. Ordena as 27 UFs oficiais.
  2. Processa somente uma UF por vez.
  3. Dentro da UF usa lotes/workers conforme o perfil de CPU do Render.
  4. Quando a UF termina, grava um JSON persistente.
  5. Só depois libera a próxima UF.
  6. Se o Render reiniciar, os JSONs concluídos são reaplicados à base e esses estados são pulados.
  7. O Excel consolidado é enviado ao Cloud somente quando a execução nacional termina.

Configuração sem alterar Python (Environment Variables do Render):
  RREO_SOURCE_ENABLED=true
  RREO_SOURCE_BUCKET=appdowelever-arquivos
  RREO_SOURCE_BASE_PREFIX=01_Arquivo_dos_Estados_RREO_e_FNDE/4_APPDOWELEVER/
  RREO_BIMESTRE=6

FNDE:
  permanece com o fluxo atual. O novo bucket ainda não possui FNDE e por isso nenhuma estrutura FNDE nova foi presumida.
